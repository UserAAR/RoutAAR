# Contributing to Routaar

Thanks for your interest in contributing! Here’s how to get started.

## Development

1. Fork and clone the repo
2. Install dependencies with `pnpm install`
3. Create a branch `feat/your-change`
4. Run locally `pnpm dev`
5. Lint and typecheck `pnpm lint && pnpm typecheck`
6. Commit with clear messages
7. Open a pull request

## Guidelines

- Keep UI consistent with existing components
- Avoid `any`; prefer strict typing
- Write small, focused commits
- Update docs for user-facing changes

## Issues

- For bugs, use the Bug report template
- For features, use the Feature request template
